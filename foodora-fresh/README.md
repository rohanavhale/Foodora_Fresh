# FoodoraFresh

A production-style food delivery frontend demo with original branding, responsive UI, React Router, Tailwind CSS, mock restaurant/menu data, and persistent cart state.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Included

- Home, restaurant listing, restaurant details, cart, checkout, login/signup, and orders pages
- 15 restaurants and 40+ menu items
- Search, cuisine filtering, vegetarian filtering, sorting
- Add/remove/increase/decrease cart quantities
- Cart persistence via localStorage
- Checkout validation and order confirmation
- Responsive mobile navigation
- Accessible labels and touch-friendly controls
- Unsplash image URLs used as remote demo imagery
